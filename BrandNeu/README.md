# Brand NUE — Next-Generation App Concept

Interactive mockup for the platform-upgrade pitch (Sept 2026).

- `index.html` — the whole mockup, one self-contained file. Open it in Chrome/Safari on a laptop (best at 1280px+ wide so the before/after panel shows). Needs internet only for Google Fonts and the Unsplash recipe/product photos; everything else is inline.
- `current-app/` — screenshots of the live app, also embedded inside `index.html` for the "Current app / Before" panel.

Use the left-hand **Screens** index to jump anywhere during the meeting. Screens tagged **NEW** are the upgrade scope (in-app AI assistant, in-app store and checkout, guides/templates/videos rendered natively). Everything else is an existing feature redesigned.
