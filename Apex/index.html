The demonstration to run on the call

Create an account, open a locked deal as a free member, take the membership, unlock it and read the code. Then open the business portal and verify that same code at the counter.

The code that links both sides

A member is holding APX-9QM2-4417 for Rosewood Salon's 20% colour offer. Type it into the business portal to see the verification, then mark it redeemed.
